response:
Launch crashes are usually Java, memory, missing files, or version mismatch issues.

First check `/status` for the recommended Java and RAM settings. Then confirm the installed pack version matches the current server or playtest version.

If it still fails, use **Crash / logs** in the Support Hub or `/crash file:<latest.log>` so staff can review the log.
