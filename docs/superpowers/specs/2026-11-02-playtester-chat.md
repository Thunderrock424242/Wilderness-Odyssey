# Playtester inbox

The user approved implementing and finishing two-way Discord DM / website playtester conversations, private diagnostic attachments, and campaign update broadcasts. Joining the Discord server is suggested and optional. Staff must be Discord administrators explicitly selected by the server owner; the server owner retains access automatically. This selection grants inbox access only, never Discord roles or unrelated website authority.

Reuse the bot's SQLite database, Discord identity, enrolled administrator sessions, Pages gateway and current website layouts. Add a private staff inbox, owner-only approval controls and campaign broadcasts on the website. No second authentication system. Outsider testers may converse while they have an active claimed membership or a valid pending invitation. Multiple campaigns require a DM campaign selection, never fan-out of a private reply. Invitation/welcome text explains forwarding to the selected admin team. Support chat opt-out/resume and announcement opt-out. Revocation stops new reads, writes and queued delivery.

Store messages for 90 days with message-ID deduplication and bounded history, attachment and aggregate storage limits. Accept text diagnostics and Spark profile files only, fetch only bounded Discord CDN HTTPS resources without redirects, redact text diagnostics, serve authenticated downloads as attachments, and never fetch Spark viewer URLs. Staff replies/announcements have durable recipient snapshots, idempotency, bounded dispatch, current admin/owner approval and tester eligibility rechecks, plus explicit sent/failed/unknown states. Ambiguous Discord sends are not blindly retried.

Implement in the existing bot checkout and a separate managed website worktree; preserve previous uncommitted bot changes. Do not deploy, register live commands or send real messages while testing. Validate bot compiler/build/full suite on Node 22 and website verify/browser tests. User's instruction to start and finish resolves the earlier design question and opts out of further process approvals.
